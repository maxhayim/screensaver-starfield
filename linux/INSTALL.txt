Starfield for Linux (XScreenSaver)

1. Install XScreenSaver if you don't have it, e.g. sudo apt install xscreensaver
   The program needs libX11, libXext, and libXft (already there on most desktops).
2. Run ./install.sh
3. Open xscreensaver-settings and choose Starfield. If it isn't listed, add
   "screensaver-starfield -root" to the programs: list in ~/.xscreensaver.

Try it in a window first:  ./screensaver-starfield -window
Every option:              ./screensaver-starfield -help
More: https://github.com/maxhayim/screensaver-starfield
